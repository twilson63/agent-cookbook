## Stacking specializations

Specializations are additive. A developer agent with G-Brain is more capable than one without. GPT-5.5 improves any specialization that does heavy reasoning. Stack them based on what you're building.

| What you're building | Recommended stack |
|---|---|
| A sharp personal assistant | Core + GPT-5.5 |
| A shipping developer teammate | Core + GPT-5.5 + Developer Agent + G-Brain |
| Infrastructure watchdog | Core + SRE Agent |
| A creative production partner | Core + Graphic Designer + Slides & Video |
| A full-stack working agent | Core + GPT-5.5 + Developer Agent + G-Brain + SRE Agent |
