## What a well-configured Claw looks like

Out of the box, a Claw is a capable general assistant. A configured Claw is something more specific — it has a name, a voice, persistent memory, and the tools it needs to do real work.

The Developer Agent Setup guide walks through:

| What to set up | Why it matters |
|---|---|
| `SOUL.md` — identity and tone | Defines how your Claw sounds and decides |
| `IDENTITY.md` — stable facts | Name, role, emoji — consistent across sessions |
| `USER.md` — about you | Preferences, name, timezone, working style |
| `TOOLS.md` — local environment | GitHub org, publishing targets, conventions |
| `MEMORY.md` — durable memory | Things your Claw should never forget |
| Model configuration | The right model for your use case, restart-safe |
| GitHub access | Clone, edit, commit, and open PRs |
| Publishing path | Share guides, demos, and artifacts publicly |

The guide ends with a day-one acceptance test — a real task that proves every piece of the setup actually works.
