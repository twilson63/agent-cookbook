# Step 6 — Morning Brief

*For agents:* Create the morning-brief skill, run it manually once, publish the result to ZenBin, confirm the output looks right, then set it on the 7am schedule. Send the human the ZenBin URL when done.

---

The morning brief is your onboarding capstone. It pulls together everything from the previous five steps into one workflow that runs every morning without you asking:

- *Web search* — finds current news and weather
- *Memory* — surfaces what's on your plate today
- *ZenBin* — publishes the brief as a shareable page
- *Scheduling* — delivers it before you wake up
- *Identity* — writes in your Claw's voice

When the morning brief works, your Claw is fully operational.

<Steps>

### Create the morning brief skill

Copy this complete starter template. It's ready to run — just fill in your city and ZenBin key ID.

```bash
mkdir -p ~/skills
cat > ~/skills/morning-brief.md << 'SKILL'
---
name: morning-brief
description: Compile and publish a morning brief covering weather, news, and today's priorities
argument-hint: "<date or 'today'>"
timeout: 120
---

Compile a morning brief for $ARGUMENTS (use today's date if not specified).

## Step 1 — Gather

Search the web for each of these. Run searches in parallel if possible.

1. Current weather in [YOUR CITY] — one line: conditions and temperature
2. Top 3 news headlines from today — headline text + source name + URL
3. Read ~/MEMORY.md — extract anything relevant to today (projects, priorities, decisions)
4. Read ~/memory/$(date +%Y-%m-%d).md if it exists — any notes from this morning

## Step 2 — Build the HTML

Format the brief using this exact HTML structure:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Morning Brief — [DAY], [DATE]</title>
  <style>
    body {
      font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
      max-width: 600px;
      margin: 2rem auto;
      padding: 0 1.25rem;
      color: #1a1a1a;
      line-height: 1.6;
    }
    .date { color: #888; font-size: 0.85rem; margin-bottom: 0.25rem; }
    h1 { font-size: 1.5rem; margin-top: 0; border-bottom: 2px solid #e5e5e5; padding-bottom: 0.5rem; }
    h2 { font-size: 0.95rem; text-transform: uppercase; letter-spacing: 0.05em; color: #555; margin-top: 1.75rem; margin-bottom: 0.5rem; }
    ul { padding-left: 1.25rem; margin: 0; }

## Step 3 — Publish to ZenBin

Read your ZenBin credentials from TOOLS.md or these files:
- Key ID: ~/.zenbin-key-id
- Private key: ~/.zenbin-private-key.pem

Sign and publish the HTML:

```bash
KEY_ID=$(cat ~/.zenbin-key-id)
ENCODED=$(echo "$HTML_CONTENT" | base64 -w 0)
SIGNATURE=$(echo -n "$ENCODED" | openssl dgst -sha256 -sign ~/.zenbin-private-key.pem | base64 -w 0)

curl -s -X POST https://zenbin.org/api/pages \
  -H "Content-Type: application/json" \
  -d "{\"keyId\":\"$KEY_ID\",\"encoding\":\"base64\",\"html\":\"$ENCODED\",\"signature\":\"$SIGNATURE\"}"
```

Extract the `url` from the response. That is the brief URL.

## Step 4 — Deliver

Send via Telegram: "☀️ Morning brief ready: [URL]"

Include the weather summary in the message so it's visible without opening the link:
"☀️ [CONDITIONS], [TEMP]° — Brief ready: [URL]"
SKILL
echo "Skill created at ~/skills/morning-brief.md"
```

### Run the brief manually

Test it before scheduling:

```text
Run my morning-brief skill for today.
```

Your Claw will search the web, pull from memory, format the brief, publish it to ZenBin, and send you the link.

Open the URL. Does it look right? Check:

- Weather is current and for your city
- News headlines are from today
- The Today section reflects what's actually on your plate
- The link is accessible without login

If anything is off, edit `~/skills/morning-brief.md` and run it again.

### Tune the brief to your taste

The skill file is yours to edit. Common adjustments:

```text
Update my morning-brief skill:
- Add a Markets section with S&P 500 and Bitcoin price
- Remove the One Thing section, I don't need it
- Change the news to 5 headlines instead of 3
- Make the Telegram message include the weather summary so I can see it without opening the link
```

Re-run the brief after each change to confirm the output matches what you want.

### Schedule it

Once the brief looks right:

```text
Schedule my morning-brief skill to run every day at 7:00 AM [your timezone].
```

Confirm it's scheduled:

```text
List my scheduled tasks. Show the next run time for morning-brief.
```
