# Module 1: Reverse Prompting 🧠

**8 lessons · ~60 minutes**

Most AI frustration isn't an AI problem — it's a context problem. This module teaches you to flip the dynamic: instead of guessing what to ask, you make the agent ask *you* the questions that matter before it starts working.

<Callout type="info">
Work through these lessons in order. Each one builds directly on the last.
</Callout>
