# Module 3: Multi-Agent & Delegation 🤝

**7 lessons · ~45 minutes**

One agent trying to do everything produces mediocre results at every step. This module teaches you to decompose work into roles, run agents in parallel, write clean handoffs, and supervise without micromanaging.

<Callout type="info">
This is the capstone module. Modules 1 and 2 are prerequisites — the delegation patterns here assume you can prompt well and manage context.
</Callout>
