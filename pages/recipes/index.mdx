# Recipes

Recipes are ready-to-follow blueprints for automating real business tasks with AI agents. Each recipe explains exactly what the agent does, what tools it needs, and what results to expect.

<Callout type="info">
These recipes are written for **business users** — no coding required. Each one can be implemented using the tools in the [Tools](/tools) section, most without writing a single line of code.
</Callout>

## How to read a recipe

Each recipe follows the same format so you always know what to expect:

1. **Overview** — a one-paragraph summary of what the recipe does and why it matters
2. **Use Case** — the specific business problem this agent solves and who it is for
3. **Agent Architecture** — the agents, tools, and integrations required to run this workflow
4. **Implementation Steps** — a step-by-step walkthrough of exactly what the agent does
5. **Example Prompts** — real prompt examples you can copy, adapt, and use immediately
6. **Expected Results** — time savings and outcomes from real-world deployments
7. **Tips & Variations** — ways to extend or adapt the recipe for your situation
8. **Getting Started** — the fastest path to running this today

## What makes a good recipe candidate?

The best processes to automate with agents share a few traits:

- **Repetitive** — the same steps happen over and over, triggered by the same inputs
- **Rule-based** — there are clear criteria for what "correct" looks like
- **High volume** — the time savings compound across many instances
- **Multi-system** — the task requires pulling information from or pushing data to multiple tools
- **Human bottleneck** — a person is currently the glue connecting different systems

If the process you have in mind checks at least three of these boxes, it is a strong recipe candidate.
